---
title: Open links in Chrome (iOS)
weight: 66
---

When ocman runs as a Home Screen web app on iPhone or iPad, iOS opens external
links in Safari and ignores your default-browser setting. Under
**Settings → Behaviour**, enable **Open external links in Chrome** to open them
in Google Chrome instead.

The setting is off by default and saved for the current browser only. The
Behaviour tab appears only on iPhone and iPad. On other devices it is hidden,
and a saved value has no effect.

Only links to other sites are affected. Links within ocman, `mailto:` and
`tel:` links, and clicks with a modifier key behave as before.

Chrome must be installed. A web app cannot check for it, so if Chrome is
missing, external links will fail to open while the setting is on.
