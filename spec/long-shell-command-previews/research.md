# Long shell command input previews

Date: 2026-10-17

## Conclusion

Three verified implementations constrain **command input**, not merely output: Codex CLI clips its compact command header, Roo Code puts command code blocks in a default height-limited viewport, and OpenCode's current session UI puts commands behind a single-line collapsible trigger. Cline's output limits are not an input-preview precedent.

For ocman, keep the Bash description and show a small, bounded command preview underneath. Offer explicit expansion and a copy-full-command action. A failed command should expose its error, not automatically expand a huge script.

## Scope

Public first-party source reads only. No application code changes, live-app experiments, commits, or writes to user databases. Notes follow the existing `spec/<topic>/research.md` convention. Links pin the inspected upstream revisions, which are not guarantees about every released client. Numeric limits below are attributed to their exact rendering path.

## Verified implementations

### Codex CLI

- **Compact command input:** `compact_command_lines` takes only the first highlighted logical command line, appends ` …` if another line exists, then clips the resulting header to the available terminal width. There is no fixed character count in this path. Nonzero exit status changes the title to `Exited (status …)` but uses the same clipping. [Command renderer](https://github.com/openai/codex/blob/ce0323f2f2d3b25e82806cd555237da3db4e1897/codex-rs/tui/src/exec_cell/compact.rs#L80-L112), [width clipping helper](https://github.com/openai/codex/blob/ce0323f2f2d3b25e82806cd555237da3db4e1897/codex-rs/tui/src/history_cell/activity_preview.rs#L17-L20).
- **Separate noncompact display path:** wraps command text first, retains the header plus **two continuation rows**, and adds an omission row when more remain. That is up to three rows of command text, plus the omission indicator, not a three-logical-line split. [Wrap and limit](https://github.com/openai/codex/blob/ce0323f2f2d3b25e82806cd555237da3db4e1897/codex-rs/tui/src/exec_cell/render.rs#L496-L557), [two-row constant](https://github.com/openai/codex/blob/ce0323f2f2d3b25e82806cd555237da3db4e1897/codex-rs/tui/src/exec_cell/render.rs#L837-L841), [omission row](https://github.com/openai/codex/blob/ce0323f2f2d3b25e82806cd555237da3db4e1897/codex-rs/tui/src/exec_cell/render.rs#L642-L652).
- **Disclosure and retained input:** multiline or width-overflowing commands advertise hidden details. Local disclosure starts with an empty expanded set and supports mouse toggling and keyboard acceptance. The detailed renderer wraps the full retained command without the preview limit. These sources establish the mechanisms, not which rendering mode every installation selects. [Disclosure detection](https://github.com/openai/codex/blob/ce0323f2f2d3b25e82806cd555237da3db4e1897/codex-rs/tui/src/exec_cell/compact.rs#L48-L56), [default collapsed state](https://github.com/openai/codex/blob/ce0323f2f2d3b25e82806cd555237da3db4e1897/codex-rs/tui/src/transcript_view/disclosure.rs#L24-L38), [mouse and keyboard controls](https://github.com/openai/codex/blob/ce0323f2f2d3b25e82806cd555237da3db4e1897/codex-rs/tui/src/transcript_view/disclosure.rs#L136-L209), [full command renderer](https://github.com/openai/codex/blob/ce0323f2f2d3b25e82806cd555237da3db4e1897/codex-rs/tui/src/exec_cell/transcript.rs#L23-L35).
- **Output is separate:** the compact renderer takes the last **three output lines**, clips them to width, and uses them below the command header. Do not describe that constant as an input limit. [Output preview](https://github.com/openai/codex/blob/ce0323f2f2d3b25e82806cd555237da3db4e1897/codex-rs/tui/src/exec_cell/compact.rs#L113-L128), [output detail constant](https://github.com/openai/codex/blob/ce0323f2f2d3b25e82806cd555237da3db4e1897/codex-rs/tui/src/history_cell/activity_preview.rs#L7).

### Roo Code

- **Command input really uses the bounded component:** `CommandExecution` passes the whole command to `<CodeBlock source={command} language="shell" />`, with no overrides. `CodeBlock` defaults `initialWindowShade=true` and `initialWordWrap=true`. Its default collapsed height is **500 px**, with vertical scrolling; expanding removes `max-height`. This is a viewport bound, not character truncation or a small fixed-line preview. [Command call site](https://github.com/RooCodeInc/Roo-Code/blob/b867ec9145750d0ae1ff7f02d35406e9bf2a0b16/webview-ui/src/components/chat/CommandExecution.tsx#L202-L205), [500 px constant](https://github.com/RooCodeInc/Roo-Code/blob/b867ec9145750d0ae1ff7f02d35406e9bf2a0b16/webview-ui/src/components/common/CodeBlock.tsx#L15-L19), [height, scrolling and wrapping CSS](https://github.com/RooCodeInc/Roo-Code/blob/b867ec9145750d0ae1ff7f02d35406e9bf2a0b16/webview-ui/src/components/common/CodeBlock.tsx#L116-L145), [defaults](https://github.com/RooCodeInc/Roo-Code/blob/b867ec9145750d0ae1ff7f02d35406e9bf2a0b16/webview-ui/src/components/common/CodeBlock.tsx#L168-L180).
- **Expand/collapse and full copy:** the code block offers a window-shade toggle and copy button. Copy uses `rawSource` when supplied, otherwise the full `source`, not visible text. [Copy implementation](https://github.com/RooCodeInc/Roo-Code/blob/b867ec9145750d0ae1ff7f02d35406e9bf2a0b16/webview-ui/src/components/common/CodeBlock.tsx#L584-L597), [controls](https://github.com/RooCodeInc/Roo-Code/blob/b867ec9145750d0ae1ff7f02d35406e9bf2a0b16/webview-ui/src/components/common/CodeBlock.tsx#L620-L661).
- **Output disclosure is independent:** `isExpanded` initializes from `terminalShellIntegrationDisabled`, and the execution-header chevron controls `OutputContainer`, not the command code block. [Output state](https://github.com/RooCodeInc/Roo-Code/blob/b867ec9145750d0ae1ff7f02d35406e9bf2a0b16/webview-ui/src/components/chat/CommandExecution.tsx#L44-L55), [chevron](https://github.com/RooCodeInc/Roo-Code/blob/b867ec9145750d0ae1ff7f02d35406e9bf2a0b16/webview-ui/src/components/chat/CommandExecution.tsx#L188-L205), [output container](https://github.com/RooCodeInc/Roo-Code/blob/b867ec9145750d0ae1ff7f02d35406e9bf2a0b16/webview-ui/src/components/chat/CommandExecution.tsx#L223-L230).

### OpenCode, current session UI

- **Collapsed shell input:** the `shell` renderer shows the command as `ShellSubmessage` only while closed. Its subtitle CSS uses `white-space: nowrap`, `overflow: hidden`, and `text-overflow: ellipsis`; the shell wrapper also clips width. This bounds the preview to a single visual row by available width, not a character cap. [Shell renderer](https://github.com/anomalyco/opencode/blob/22e771f5893e255ea78fc10557ed3fb98d3a1072/packages/session-ui/src/tools/tool-renderer.tsx#L2009-L2040), [subtitle CSS](https://github.com/anomalyco/opencode/blob/22e771f5893e255ea78fc10557ed3fb98d3a1072/packages/session-ui/src/components/basic-tool.css#L104-L109), [shell clipping CSS](https://github.com/anomalyco/opencode/blob/22e771f5893e255ea78fc10557ed3fb98d3a1072/packages/session-ui/src/components/shell-submessage.css#L9-L23).
- **Defaults and controls:** `BasicTool` defaults closed when `defaultOpen` is omitted, but accepts controlled `open` and caller overrides. It renders a collapsible trigger, arrow and content. Do not infer that every parent always leaves shell calls closed. [Default state](https://github.com/anomalyco/opencode/blob/22e771f5893e255ea78fc10557ed3fb98d3a1072/packages/session-ui/src/components/basic-tool.tsx#L111-L120), [trigger and content](https://github.com/anomalyco/opencode/blob/22e771f5893e255ea78fc10557ed3fb98d3a1072/packages/session-ui/src/components/basic-tool.tsx#L293-L362).
- **Full command on expansion and copy:** the body renders the full command and output as separate spans, while `ConsoleOutput` receives only the full command for its copy action. [Body and copy payload](https://github.com/anomalyco/opencode/blob/22e771f5893e255ea78fc10557ed3fb98d3a1072/packages/session-ui/src/tools/tool-renderer.tsx#L2001-L2005), [clipboard handler](https://github.com/anomalyco/opencode/blob/22e771f5893e255ea78fc10557ed3fb98d3a1072/packages/session-ui/src/tools/tool-renderer.tsx#L1882-L1901).
- **Different surface, different behavior:** the web share viewer renders the complete command above an output-only **10-line clamp** with Show more/Show less. That clamp does **not** constrain command input. [Separate command/output nodes and expansion](https://github.com/anomalyco/opencode/blob/22e771f5893e255ea78fc10557ed3fb98d3a1072/packages/web/src/components/share/content-bash.tsx#L40-L63), [output-only clamp](https://github.com/anomalyco/opencode/blob/22e771f5893e255ea78fc10557ed3fb98d3a1072/packages/web/src/components/share/content-bash.module.css#L71-L83).

## Counterexamples and evidence limits

### Cline

The command row renders the entire command through `CodeBlock forceWrap={true}`. That mode sets `overflowY: visible` and `maxHeight: none`. There is no input-preview line or character cap in this inspected path. [Command input](https://github.com/cline/cline/blob/a42df8c8d5fd9d9f9a9073589baffe32ea9bb2f0/apps/vscode/webview-ui/src/components/chat/CommandOutputRow.tsx#L234-L245), [code block styling](https://github.com/cline/cline/blob/a42df8c8d5fd9d9f9a9073589baffe32ea9bb2f0/apps/vscode/webview-ui/src/components/common/CodeBlock.tsx#L149-L158).

Its **five-line threshold**, **75 px** limited viewport and **200 px** expanded viewport belong to `CommandOutputContent`, with a separate expand handle. They cannot justify truncating command input by analogy to Cline. [Output threshold](https://github.com/cline/cline/blob/a42df8c8d5fd9d9f9a9073589baffe32ea9bb2f0/apps/vscode/webview-ui/src/components/chat/CommandOutputRow.tsx#L25-L28), [output viewport limits](https://github.com/cline/cline/blob/a42df8c8d5fd9d9f9a9073589baffe32ea9bb2f0/apps/vscode/webview-ui/src/components/chat/CommandOutputRow.tsx#L94-L109).

### Claude Code

The official changelog confirms that a long shell-command preview can be cut off: it records a fix for a garbled character when a "long shell-command or agent-description preview was cut off mid-emoji." That establishes some command-preview truncation, but does not identify the exact surface, numeric cap, default, or disclosure behavior. I did not verify those details and would not cite an assumed three-line Bash-input rule. [Official changelog](https://github.com/anthropics/claude-code/blob/c017428c8c27e604840435048d5bce6a9a22c040/CHANGELOG.md#L3713-L3714).

### Aider

The inspected suggested-command execution path passes the complete joined command lines as the approval subject, then prints `Running {command}` for each executed line. Its subject renderer pads and prints multiline subjects in full; `tool_output` forwards text to the console without an explicit preview cap. No collapsible input-preview implementation was established in this path. This is not a claim about every Aider frontend. [Suggested commands](https://github.com/Aider-AI/aider/blob/5dc9490bb35f9729ef2c95d00a19ccd30c26339c/aider/coders/base_coder.py#L2450-L2475), [subject rendering](https://github.com/Aider-AI/aider/blob/5dc9490bb35f9729ef2c95d00a19ccd30c26339c/aider/io.py#L848-L857), [console output](https://github.com/Aider-AI/aider/blob/5dc9490bb35f9729ef2c95d00a19ccd30c26339c/aider/io.py#L995-L1012).

## Recommendation for ocman

These are proposed defaults, not upstream product claims.

1. Keep description, execution status and error summary outside the input preview.
2. Default to the first **three visual rows** of command input, plus an explicit "Show full command" control when clipped. Count wrapping, not just newline characters. A single huge `sd` argument must not bypass the height bound.
3. Bound long lines by available width. Clip or wrap inside that row budget. If preview text is precomputed, also apply a render-budget character cap; do not mutate or truncate stored input. Choose and test that cap locally rather than attributing one to another product.
4. Expansion reveals the complete command with an obvious collapse control. "Copy command" always copies the original full command, including newlines, even while collapsed. Keep output controls and copy-output behavior separate.
5. Failure should reveal the error or exit status while preserving the user's input-expansion choice. Never automatically expand a huge command because it failed.
6. Cover multiline scripts, one very long line, narrow widths, Unicode, streaming input growth, copy fidelity and failed execution in tests.
